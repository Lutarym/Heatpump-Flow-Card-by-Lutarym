# 言語パック

[English](SPRACHPAKET.md) · [Deutsch](SPRACHPAKET.de.md) · [Français](SPRACHPAKET.fr.md) · **日本語**

言語パックを使うと、カードを自分で別の言語に翻訳したり、内蔵の翻訳を調整したりできます。言語パックは、カードとヘルプのすべてのテキストを含む JSON 形式のテキストファイルです。

## 場所

カードを編集し、エディターを **詳細** に切り替え、**インポート・エクスポートとカスタマイズ** セクションの **言語** の下：

- **言語を書き出す**：表示中の言語をファイルとしてダウンロードフォルダに保存
- **言語を読み込む**：言語ファイルを読み込んで選択
- **独自の言語を削除**：独自またはカスタムの言語の場合のみ表示

## 新しい言語に翻訳する

1. **言語** で翻訳元の言語（例：English）を選び、**言語を書き出す** を押します。
2. テキストエディターでファイルを開き、先頭の `code`（例：`"nl"`、`"pt-br"`）、`name`（例：`"Nederlands"`）、`dezimal`（`","` または `"."`）を変更します。`basis` は書き出した言語のままにします。
3. `texte` と `hilfe` では、コロンの右側のテキストだけを翻訳します。左側のキーは変更しません。
4. `{v}`、`{n}`、`{liste}` などの波かっこのプレースホルダーは、翻訳文にもそのまま残してください。カードがそこに数値や名前を入れます。
5. **言語を読み込む** を押してファイルを選びます。取り込んだテキスト数が表示されます。
6. 言語を保持するため、Home Assistant のエディターの保存ボタンを押します。

一度にすべてを翻訳する必要はありません。ないか空のテキストは基本言語（`basis`）で表示されます。

## 内蔵の言語を調整する

たとえば日本語を書き出し、一部のテキストを変更して `"code": "ja"` のまま読み込みます。選択リストに「（カスタム）」と表示されます。**独自の言語を削除** で内蔵の翻訳に戻ります。

## ファイルの構成

キーはドイツ語で、このとおりに書く必要があります。

```json
{
  "format": "lutarym-sprachpaket",
  "version": 1,
  "karte": "4.2.0",
  "code": "nl",
  "name": "Nederlands",
  "basis": "en",
  "dezimal": ",",
  "texte": {
    "s_cop": "Gem. COP vandaag {v}",
    "t_jaz": "Jaarrendement (SPF)"
  },
  "hilfe": {
    "grundlagen": "Basis",
    "grundlagen.0.n": "Lezen en schrijven",
    "grundlagen.0.t": "Elke regel laat zien waar de waarde vandaan komt."
  }
}
```

| キー | 意味 |
|---|---|
| `format` | 常に `"lutarym-sprachpaket"` |
| `version` | 常に `1` |
| `karte` | 書き出し時のカードのバージョン（参考） |
| `code` | 言語コード：小文字 2〜3 文字、地域付きも可。例：`"nl"`、`"pt-br"` |
| `name` | 選択リストに表示する名前 |
| `basis` | ないテキストに使う基本言語：`de`、`en`、`fr`、`ja` |
| `dezimal` | 小数点記号：`","` または `"."` |
| `texte` | カードとエディターのすべてのテキスト |
| `hilfe` | グループ名（`grundlagen`）と、各ヘルプ項目の名前（`.n`）と説明（`.t`） |

## 読み込み時のチェック

- 不明なキーは無視され、件数が表示されます。
- テキストのプレースホルダーが元と一致しない場合は基本言語を使い、該当するキーを表示します。
- ないテキストの件数を表示します。
- 山かっこ `< >`、半角の二重引用符 `"`、バッククォートを含むテキストは拒否され、基本言語を使います。「 」や “ ” などの引用符は使えます。

## 保存場所

読み込んだ言語はこのカードの設定の `language_custom` に保存され、このカードにだけ適用されます。インポート・エクスポートとカスタマイズ セクションの **ファイルに保存** と **ファイルから読み込み** で、言語を含む設定全体を別のカードに移せます。言語が **自動** で Home Assistant が同じ言語コードを使っている場合、カードは独自の言語を自動的に使います。

ヘルプを含めて全部翻訳すると、カードの設定はかなり大きくなります。

## カードの更新後

新しいバージョンで追加されたテキストは古い言語ファイルにはなく、基本言語で表示されます。その場合は言語をもう一度書き出してください。ファイルには再びすべてのテキストが入り、新しいものは基本言語になっているので、それだけを翻訳します。
